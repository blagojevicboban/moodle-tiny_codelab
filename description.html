CodeLab: Runnable Program Examples in the VS Code Editor

Insert program examples in C, C++, Python, Java, C#, JavaScript, Pascal and PHP into any Moodle text, write them in the code editor of VS Code and run them on a Jobe server or in the browser.

Live demo: try the CodeLab plugins on codelab.tsp.edu.rs. Look around as a guest (Python runs in the browser), or use the demo accounts teacher and student (password Demo-2026) to run every language, the debugger and SQL. Everything is reset every night.

What's New in v1.12.0

  • Pointers in the memory view: with CodeLab runner 0.6.0, C and C++ pointers are arrows: a pointer walking through an array stands under its cell, a pointer to a variable reads &name, and a linked list on the heap is drawn node by node down to NULL.
  • From the flowchart to CodeLab: Open in CodeLab of the Algorithm plugins starts a new CodeLab example with the code of the flowchart.
  • Safer runner: session tokens are for one language, a shared runner can have a secret for each site, and runs for grading cannot be sent twice.

Core features

  • The code editor of VS Code: Monaco, with syntax highlighting, line numbers, bracket matching and search.
  • Typing help for every language: for Python from Jedi, for the others keywords, snippets, library functions with their parameters, and members of strings, lists and Scanner. Teachers can turn it off for a single example.
  • Run on Jobe: programs are compiled and run on your Jobe server, with an input field. There is a rate limit per user and a size limit.
  • Python in the browser: with Pyodide, input asks for the input while the program runs. Step goes line by line with the variables, and Stop also ends an endless loop.
  • Debugger: breakpoints, Step over and out, call stack, step back and a timeline, for Python and C/C++.
  • Memory view: frames and the objects their variables point to, with arrows; changed cells green, index variables under their cell.
  • Complexity: a Python example runs for sizes n from 10 to 500, its steps are drawn beside n, n log n and n², and the growth is named.
  • Flowchart bridge: with the Algorithm plugins, Python examples are also drawn as flowcharts that run step by step.
  • VS Code themes and phones: Light, Dark and High Contrast with Auto dark mode; a check button sends input on phones.
  • Default input: saved with the example, so readers start from it.
  • Simple markup: an example is a pre element with class names, which survive Moodle's HTML cleaning.

The CodeLab plugins

  • CodeLab for TinyMCE (this plugin): inserts examples in the TinyMCE editor. The other two plugins use its editor and runner.
  • CodeLab filter: turns examples into code editors that readers can edit and run.
  • CodeLab question type: programming questions graded on Jobe with tests.

Requirements

  • Moodle: 4.5 LTS to 5.3 (PHP as required by your Moodle version).
  • Jobe server: for running programs. Set its address and API key in the plugin settings. Python in the browser works without it.
  • Python in the browser: Chrome or Edge 137 or newer. Other browsers run Python on Jobe.
  • CodeLab filter: install it too and switch the filter On in Site administration, Plugins, Filters, Manage filters. Without it readers see the examples as plain code.

Privacy

Programs and their input are sent to the Jobe server set by the administrator to be compiled and run. Interactive runs, the debugger and SQL go to the CodeLab runner server set by the administrator instead, with a short-lived signed token that holds only the numeric user id; the runner keeps nothing after the session ends. Nothing is stored in Moodle. When Python runs in the browser, the browser downloads Pyodide from the address in the settings, by default the jsDelivr CDN. It does not send the program or its input there. The plugin implements the Moodle Privacy API.
